## Preset AP-RSEHDXU

O diretório comunitário identifica o preset Icy's Preset 1 para Sword Arena - Raid:
- Slot 1 Beyond Heaven — prioridade P2, Auto abilities.
- Slot 2 Sun God VS Dragon — prioridade P3, Auto abilities.
- Slot 3 Mr. Champion — prioridade P2, placement limit 1.
- Slot 4 Useless Goddess — prioridade P2, placement limit 1, Auto abilities.
- Slot 5 Loid — prioridade P1.
- Slot 6 Speedcart — prioridade P1.
- Hero slot vazio.

Use somente se possuir as unidades e se o mapa for compatível. O código não cria unidades faltantes.

## Limites da referência LixHub

A listagem pública do LixHub anuncia categorias como Joiner, Game, Summon, Macro, Auto Reroll, Shop, Webhook, Minigames e Misc. O loader público encaminha Anime Crusaders X ao backend Luarmor protegido/obfuscado; o payload completo não está publicado como código-fonte. O yno hub é uma implementação independente e não reproduz código proprietário.

Códigos, valores de recompensas e rótulos de interface podem mudar; confira no próprio jogo antes de iniciar uma rotina longa.
