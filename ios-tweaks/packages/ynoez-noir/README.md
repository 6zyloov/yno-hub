# ynoez noir — SnowBoard theme

**Palette:** absolute black (#000000) first; clean white (#FFFFFF) glyphs and details. No gradients, neon colors or colored accents.

A minimalist high-contrast icon theme built for SnowBoard and packaged for Dopamine Rootless.

## Included icons

Phone, Messages, Safari, Camera, Photos, Settings, Music, App Store, Mail, Calendar, Clock, Maps, Notes, Files, Weather and YouTube.

Artwork is generated at 180×180 for Plus-size iPhones. App bundle identifiers can vary by installed iOS/app version; unsupported icons stay stock.

## Install

Install ynoez noir from the ynoez Sileo source after publication, then open SnowBoard → Select Theme → ynoez noir → Apply. Respring if requested.

Requires SnowBoard. This theme changes appearance only; it does not claim to improve performance or battery life.
